# Outlook Troubleshooting Guide

## Problem: Outlook is not receiving emails

Try:

1. Check the internet connection.
2. Verify that Outlook is connected.
3. Check the mailbox for storage limitations.
4. Restart Outlook.
5. Restart the computer.
6. Check whether the issue occurs in webmail.

## Problem: Outlook is not sending emails

Check:

- Recipient email address.
- Internet connection.
- Outbox for stuck messages.
- Attachment size.
- Account authentication.

## Problem: Outlook application does not open

Restart the computer and try again.

If the problem continues, contact IT support.

Provide the exact error message when reporting the issue.
