# Laptop Startup Troubleshooting

## Problem: Laptop does not start

Check:

1. Connect the power adapter.
2. Check whether the charging indicator is active.
3. Try another approved power outlet.
4. Disconnect unnecessary external devices.
5. Hold the power button according to the device manufacturer's instructions.
6. Try starting the laptop again.

## Problem: Laptop turns on but Windows does not start

Record any error message displayed on screen.

Do not repeatedly modify BIOS or system settings without IT guidance.

## Escalation

Contact IT support if:

- The device shows no signs of power.
- The screen remains blank.
- A hardware error is displayed.
- The operating system repeatedly fails to start.
