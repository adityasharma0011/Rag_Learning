# Slow Laptop Troubleshooting

## Problem: Laptop is running slowly

Try these steps:

1. Restart the laptop.
2. Close applications that are not being used.
3. Check available disk space.
4. Open Task Manager and identify applications using excessive CPU or memory.
5. Disable unnecessary startup applications.
6. Install approved operating system updates.
7. Run the organization's approved security scan.

## Low disk space

Remove unnecessary temporary files and unused applications according to company policy.

Do not delete system files unless instructed by IT support.

## Escalation

Contact IT support if the laptop remains slow after restarting and removing unnecessary processes.
