# Internet Connection Troubleshooting

## Problem: No internet access

Follow these steps:

1. Check the Wi-Fi or Ethernet connection.
2. Check whether other devices have internet access.
3. Restart the network device if appropriate.
4. Restart the computer.
5. Check the network icon for warning messages.
6. Run the Windows Network Troubleshooter.

## If using Ethernet

Check that:

- The Ethernet cable is connected properly.
- The network port is active.
- The cable is not physically damaged.

## Escalation

Contact IT support when the device cannot obtain an IP address or the network remains unavailable after basic troubleshooting.
