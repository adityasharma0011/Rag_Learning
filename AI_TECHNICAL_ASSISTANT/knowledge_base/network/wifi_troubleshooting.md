# Wi-Fi Troubleshooting Guide

## Problem: Laptop cannot connect to Wi-Fi

Follow these steps:

1. Check that Wi-Fi is enabled on the laptop.
2. Make sure Airplane Mode is turned off.
3. Check whether other devices can connect to the same Wi-Fi network.
4. Restart the Wi-Fi router if the problem affects multiple devices.
5. Forget the Wi-Fi network and connect again.
6. Restart the laptop.
7. If the issue continues, restart the network adapter.

## Forget and reconnect to Wi-Fi

On Windows:

1. Open Settings.
2. Go to Network & Internet.
3. Select Wi-Fi.
4. Select Manage known networks.
5. Select the network.
6. Choose Forget.
7. Connect to the network again and enter the password.

## When to contact IT support

Contact IT support if:

- Other networks also fail to connect.
- The Wi-Fi adapter is missing.
- The laptop repeatedly disconnects.
- The issue continues after restarting the device.
