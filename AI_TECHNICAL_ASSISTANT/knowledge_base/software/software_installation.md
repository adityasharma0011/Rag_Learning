# Software Installation Guide

## Installing approved software

Only install software that is approved by the organization.

General process:

1. Check whether the software is approved.
2. Download it from the official or organization-approved source.
3. Close unnecessary applications.
4. Run the installer.
5. Follow the installation instructions.
6. Restart the computer if required.
7. Verify that the software works correctly.

## Security

Do not install cracked, pirated, or unknown software.

Do not disable antivirus or endpoint security to install software unless specifically instructed by authorized IT personnel.

## Installation failure

Record:

- Software name
- Version
- Operating system
- Error message

Provide this information to IT support.
