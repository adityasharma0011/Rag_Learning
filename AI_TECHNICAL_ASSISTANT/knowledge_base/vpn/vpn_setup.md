# VPN Setup Guide

## Purpose

A VPN allows employees to securely access company resources from an external network.

## Basic VPN setup

1. Install the company-approved VPN client.
2. Open the VPN application.
3. Enter the company VPN server address.
4. Enter your authorized company credentials.
5. Complete multi-factor authentication if required.
6. Select Connect.
7. Verify that the VPN status shows Connected.

## Security

Never share your VPN credentials with another person.

Do not install VPN software from untrusted sources.

## If setup fails

Contact IT support with:

- VPN client name
- Operating system
- Error message
- Screenshot of the error if permitted
